# 项目记忆 · 引力物流  GRAVITY FREIGHT

---

## 一、项目身份

一句话：单文件 HTML5 Canvas 太空物流经营游戏，融合 OpenTTD 式航线网络与 SpaceX 式发射回收。

核心循环：签约 → 铺航线 → 造火箭 → 发射 → 入轨对接 → 交付赚钱 → 扩张星域

技术约束：
- 纯前端单文件，无构建工具，无外部依赖（字体用 Google Fonts 可降级）
- Canvas 2D 渲染 + DOM UI 混合架构
- localStorage 持久化（版本化存档，当前 v9）
- 目标帧率 60fps，粒子船舶总数硬上限

---

## 二、技术架构

```
┌─────────────────────────────────────────────┐
│  style        全局 CSS（面板弹层动画）     │
├─────────────────────────────────────────────┤
│  body         Canvas + DOM 面板结构         │
├─────────────────────────────────────────────┤
│  script                                     │
│  ├── CONFIG  CARGO  PARTS  TECHS          │
│  ├── REPS（声望） UNLOCK_ORDER              │
│  ├── nodes[]（所有星体节点定义）              │
│  ├── 几何：polar  buildPath  pointAt       │
│  ├── 经济：spend  earn  合同生成           │
│  ├── 航线 & 货船状态机                       │
│  ├── 发射 & 助推器管线                       │
│  ├── 灾变事件系统                            │
│  ├── 音效（WebAudio 合成，无外部文件）        │
│  ├── 渲染：drawXxx 系列 + render()           │
│  ├── UI 同步：ui() 每帧                      │
│  ├── 存档：saveGame  loadGame（版本化）     │
│  ├── 交互：鼠标键盘按钮事件                 │
│  └── 主循环：frame() → update + render + ui  │
└─────────────────────────────────────────────┘
```

命名规范：
- 节点对象 `{id, type, name, tag, r(), angle, locked, prod{}, cons{}, cap, stock{}, mult, ...}`
- 函数动词开头：`buildPath`, `drawStation`, `genContract`, `buyNode`
- 状态字符串常量：`'open''flying''done''failed'`、`'load''go''unload''back'`
- 颜色集中在 `root` CSS 变量，Canvas 内用字面量

## 三、视觉风格

 要素  规范 
------------
 底色  深藏青 `#070d1a`，非纯黑 
 主色  青 `#53d7e0` + 琥珀 `#f5a83c` 
 强调  金 `#ffd166`（钱）、红 `#ff5d5d`（警报）、绿 `#59d98c`（成功） 
 面板  半透明深蓝 `rgba(13,22,40,.92)` + 1px 边框 `#233552` + 琥珀角标 
 字体  中文 `Noto Sans SC`，等宽数字 `Orbitron` 
 圆角  极少用，主要直角 + 角标装饰 
 动效  呼吸灯、渐入、粒子爆发；禁止弹跳果冻 
 星空  190 颗静态闪烁点，世界坐标不随缩放 
 星体  径向渐变球体 + 特征细节（陨石坑条纹极光弧） 

绝对禁止：紫色渐变、emoji 替代图标、卡通圆角、阴影泛滥、纯白背景。

## 七、已知设计规则

1. 货船跟车：同航线同向，间距 20 停等；并列按 `id` 小者优先（防死锁）
2. 地面线：两端 `r() = RE1.2`；只有地面线可运零件
3. 发射场：只接工厂零件专线，不往外发货
4. 封锁期间：船队原地冻结，不消耗不产出
5. 创造者模式：`spend()` 永远返回 true、`earn()` 不执行、资金显示 ∞
6. 存档：版本不匹配直接弃档开新局，不做迁移

## 九、维护守则

1. 单文件原则：所有代码在一个 `.html` 内，不拆模块
2. 存档版本：每次改结构 `SAVE_KEY` 版本号 +1，不做向后兼容
3. 性能底线：粒子 ≤900、船舶 ≤30、节点标签用 `label()` 不逐个 `fillText`
4. 禁止引入：任何外部 JS 库、框架、打包工具、图片资源
5. 测试路径：创造者模式 → 解锁全部 → 触发灾变 → 验证封锁恢复
6. 回复格式：给完整可运行代码，不给片段；附简要说明变更点
